#+title: PlayMe
* PlayMe.rs!
Playme is a small and minimal audio file player for unix machines.
By using playme you can play a .mp3 or a .wav file and have that same audio continue looping.
When running with the '&' symbol you can make this program run in the background.
** Usage:
#+begin_src
A program to play a song in the background

Usage: playme [OPTIONS] --title <TITLE>

Options:
  -t, --title <TITLE>        Filepath of a track, playlist, or directory
  -c, --command <COMMAND>    append, toggle, kill, loop, next, queue, previous,
                             pause, or play [default: append]
  -n, --notify               Send desktop notifications for track changes
  -v, --view                 View the currently playing track
  -h, --help                 Print help
  -V, --version              Print version
-----------------------------------------------------------
# Example:
$ playmectl -t ~/.local/audio/StickerbushSymphony.mp3 &
$ playmectl -t ~/Music -c queue
$ playmectl -c next
$ playmectl -c toggle
#+end_src
